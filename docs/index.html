Honeypot Sensor

A public Cowrie SSH/Telnet honeypot on a locked-down cloud VM. Every session is grouped by how far the attacker got, mapped to MITRE ATT&CK and clustered into campaigns. This page rebuilds itself from the sensor's logs every night.

    How far attackers got

    Cowrie accepts weak passwords on purpose, so getting a shell reflects the honeypot's settings, not attacker skill.

    Top campaigns

    Sessions grouped by their command script (URLs and IPs normalized), ranked by unique source IP. Tags describe what the script does. The commands themselves aren't published.

    Malware samples

    Files attackers downloaded or uploaded. Hashes link to VirusTotal. Empty files and tiny shell-test writes are left out.

    MITRE ATT&CK techniques

    Highlighted rows are the rarer, more telling techniques. Muted rows show up in most sessions.

    Most-tried credentials

    Username / password pairs. Most are factory defaults for routers, DVRs and cameras.
