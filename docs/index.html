Honeypot Sensor

A public Cowrie SSH/Telnet honeypot on a locked-down cloud VM. Every session is grouped by how far the attacker got, mapped to MITRE ATT&CK and clustered into campaigns. This page rebuilds itself from the sensor's logs every night.
